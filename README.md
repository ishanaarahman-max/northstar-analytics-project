# NorthStar Analytics Project

This repository contains the complete analytical implementation for the NorthStar Urban Mobility and Logistics case study.

## Repository Contents

* **NorthStar_Project.ipynb** – Python data processing and analytics
* **02_R_SQL_Analysis.ipynb** – SQL within R analysis and statistical visualisation
* **03_MongoDB_Analysis.ipynb** – MongoDB implementation and query optimisation

## Tools Used

* Python
* R
* SQL
* MongoDB
* Google Colab
* GitHub

## Project Objective

To identify operational inefficiencies within NorthStar Urban Mobility and Logistics using integrated relational and NoSQL analytical techniques.

## Key Analytical Areas

* Service demand analysis
* Delivery performance analysis
* Route optimisation analysis
* Operational cost analysis
* Customer complaint analysis
* MongoDB document modelling
* Query optimisation
